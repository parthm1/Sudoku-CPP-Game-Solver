# Archived high-school source

`original_2022_main.cpp` is the preserved original school program. It is **not** part of the current CMake build. The current code in `src/` and `include/` uses the same six initial puzzle grids, but has a separate implementation, including a backtracking solver and automated tests.

The archive is retained to show the original project's history and distinguish it from features of the present repository.
